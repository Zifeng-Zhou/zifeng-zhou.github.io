# Zifeng Zhou — Personal Website

A lightweight static academic / professional website designed for GitHub Pages.

## Files

- `index.html` — all page content
- `styles.css` — responsive styling
- `script.js` — optional JavaScript
- `assets/Zifeng_Zhou_Resume.pdf` — CV

## Deploy with GitHub Pages

1. Create a new GitHub repository named:
   `YOUR_GITHUB_USERNAME.github.io`

2. Upload all files from this folder to the repository root.

3. In GitHub, open:
   **Settings → Pages**

4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

5. Save. GitHub will publish the site at:
   `https://YOUR_GITHUB_USERNAME.github.io`

## Before publishing

Open `index.html` and optionally add your real:
- GitHub profile
- LinkedIn profile
- Google Scholar profile (only if you actually have one)
- Personal headshot

Search for the footer comment:
